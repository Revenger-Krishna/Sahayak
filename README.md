#  Sahayak

 Sahayak is like zomato but for services , it solves the problem of finding good and reliable workers/servicemen around you. 
🔗 **Live Demo:** https://society-worker-app.vercel.app/  

---

## ✨ Key Features
* **Feature 1:** ( Wide variety of professions covering from painters to doctors ~ that too multiple individual options ~ choose as per your need/preference  )
* **Feature 2:** ( View each helpers  proof of works  , biodata (for security , authentications and trust or so ) , ratings , reviews from previous users )
* **Feature 3:** ( directly connect with the helper through the app to better state your problem explaining exactly what help you need , negotiating with prices or so )

## 🛠️ Tools Used
* **Frontend:** Next.js, React, Tailwind CSS
* **Deployment:** Vercel
* **AI**  ( Google Antigravity , Claude , Gemini )
